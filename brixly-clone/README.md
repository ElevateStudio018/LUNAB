# Brixly – återskapad startsida

Statisk återskapning av startsidan på [brixly.se](https://brixly.se/) i ren HTML, CSS och JavaScript (inga beroenden).

- `index.html` – startsidan (hero, tjänstekort, intro, hållbarhet, projekt, footer)
- `css/style.css` – layout, färger (`--brixly`, `--sand`, `--orange` …) och responsiv design
- `js/main.js` – megameny (desktop) och utfällbar mobilmeny
- `assets/` – bilder och ikoner hämtade från brixly.se

Typsnitt: Rethink Sans via Google Fonts.

## Kör lokalt

```sh
python3 -m http.server 8000
# öppna http://localhost:8000
```

Länkar till undersidor är platshållare (`#`).

> Bilder, logotyp och texter tillhör Brixly AB.
